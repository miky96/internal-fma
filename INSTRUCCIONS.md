# Instruccions sobre pasos per comencar amb el projecte

## Estat actual
- Ara mateix tenim una tool per afegir tickets, tenir un inventori i per millorar el servei
de barra gracies a una interficie que et diu que s'ha de pagar facilment.
- Aquesta web tool s'utilitza 3 dies a l'any i nomes poden entrar unes 10/20 persones tot i que ho fan simultaniament
- La web ha de funcionar rapid ja que serveix per crear tickets a partir del que diu un client en barra
- La web s'utilitza sobretot en format mobil i tablets per tant cal que tingui un molt bon disseny responsive per multiples pantalles.
- Els rols que ja hi han creats s'han de mantenir
- Esta tot a google cloud amb firebase i la base de dades es firestore.

## Canvis o propostes a fer
1. Vull que hi hagi una millora de rendiment i visual a partir del que ja hi ha aquí els svg els vull mantenir tot i que estic obert a cambiar els de les icones dels productes
2. Si cal, es pot instalar algun framework per complir amb el punt 1
3. Cal fer un repas de la infrastructura ja que es pot millorar molt en termes de CI/CD i de com s'esta gestionant el google cloud
4. Un cop fet els 3 primers punts es pot parlar de altres millores
